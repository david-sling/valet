# Third-party assets

## Emoji hands (`public/emoji/`)

- `noto/` — Noto Emoji by Google, v2.048 (github.com/googlefonts/noto-emoji). Apache License 2.0.
- `fluent/` — Fluent UI Emoji by Microsoft, commit 1ffb34c (github.com/microsoft/fluentui-emoji). MIT License.

Apple's emoji artwork is licensed for use on Apple platforms only, so it is not used here.
